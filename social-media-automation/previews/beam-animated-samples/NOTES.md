# Beam silent reel samples

Three locally generated 20-second, 1080x1920 silent MP4 previews. No cloud changes or social publishing.

These compare templates using one short topic: thanking someone and responding. Romanization is intentionally simplified, with tones omitted and a visible note. Khrap and kha examples reflect common male/female-speaker usage, not a claim that every speaker must use a particular form. The polite-upgrade sample does not label the basic phrase incorrect.

Written-language references checked for the examples:
- https://www.thaipod101.com/lesson/learn-basic-thai-in-3-minutes-4-thank-you-and-im-sorry
- https://thailanguagehut.com/thai-expression-mai-bpen-rai/

The meaning of mai pen rai varies by situation. The quiz explicitly places it as a reply to thanks, where no problem / you're welcome is appropriate. These are visual previews, not pronunciation instruction or native-speaker certification.
