WHAT WAS BUILT
================================================================================

A fully autonomous social media agent pipeline that:

1. Generates authentic LDS-focused inspirational quotes via Claude AI
2. Crafts engaging Instagram captions with optimized hashtags
3. Renders 1080×1080px graphics with random gradient backgrounds
4. Routes ALL content to Slack for manual approval (no auto-posting)
5. Publishes approved posts to Instagram, Facebook, and Threads
6. Supports iterative caption amendments based on user feedback
7. Runs autonomously via GitHub Actions on a configurable schedule
8. Handles asynchronous Slack interactions via serverless webhooks

KEY DESIGN DECISIONS
================================================================================

1. Slack-First Approval
   WHY: Manual review prevents brand misalignment, supports amendments

2. Claude for Quote & Caption Generation
   WHY: LDS-focused, context-aware, maintains authentic voice

3. Pillow for Graphics (no external APIs)
   WHY: Self-contained, deterministic, lightweight

4. Random Gradients (unique every time)
   WHY: Keeps content fresh, visually interesting

5. Async Webhook Handler (separate from scheduler)
   WHY: GitHub Actions can't do persistent webhooks

6. Environment Variables Only (no secrets in code)
   WHY: Security best practice, easy rotation

7. Deterministic Daily Selection (seeded RNG)
   WHY: Same quote per day if re-run, but sequence varies

8. Meta Graph API (not platform-specific)
   WHY: Single API for Instagram + Facebook + Threads
